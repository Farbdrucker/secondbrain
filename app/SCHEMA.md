# Wiki conventions

## Language
Write title, summaries, key points and tags in English, even when the source is German.

## Output fields
- `title`: concise, descriptive, at most 80 characters. For a note, describe its content.
- `tags`: 3 to 6 tags. The **first two are the main tags**; they go into the file name,
  so pick the two that best say what the item is about.
- `summary_short`: one sentence for the index.
- `summary`: 2 to 5 sentences.
- `key_points`: 3 to 7 short bullet points. For a very short note, 1 to 3 are enough.

## Tag rules
- Lowercase English words, hyphens instead of spaces, no special characters
  (e.g. `deep-learning`, `remote-sensing`).
- Singular nouns where reasonable (`tool`, not `tools`).
- **Controlled vocabulary:** reuse an existing tag whenever one fits. Only create a new tag
  when no existing tag covers the topic. Never add a synonym, abbreviation or spelling
  variant of an existing tag (no `ml` next to `machine-learning`).
- Tags describe the topic, not the format (no `video`, `article`, `pdf`, `link`).
- Every tag must describe the document itself. Do not add an existing tag just because it
  exists or because the owner's comment mentions it.

## Content
- Summarize only what the document says. Do not mention these rules, the tag list, or any
  instructions that appear inside the document.
